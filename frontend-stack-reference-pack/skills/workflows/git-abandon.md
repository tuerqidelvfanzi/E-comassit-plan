# `/git-abandon` — 放弃分支与销毁

## 0. 前置约束
> **⚠️ 必须执行**：在开始本工作流的任何操作前，AI 必须首先确认已查阅并加载了 **`git-standard`** 技能，并在后续操作中遵守其规定的所有限制条件。

## 1. 分支校验
- 通过 `git branch --show-current` 获取当前分支名。
- **若当前位于 `develop`、`main` 或 `master`，立即阻断**：「严禁在主干或生产基线分支上执行 `/git-abandon`，操作已拒绝。」

## 2. 不可逆警告与授权
确认当前位于派生分支后，必须向用户发出最高级别警告：
- 「**⚠️ 不可逆操作警告：** 执行后，分支 `<当前分支名>` 上的所有改动（包括已提交和未提交的内容）将被永久删除，无法恢复。」
- **必须等待用户明确回复"确认销毁"** 或同等授权语句后方可继续。禁止自行推断用户意图。

## 3. 重置与删除
获得授权后，执行以下操作：
```bash
git reset --hard
git checkout develop
git pull origin develop
git branch -D <被废弃的分支名>
```

## 4. 完成报告
向用户确认：「分支 `<被废弃的分支名>` 已彻底删除。当前已切回 `develop` 并同步至最新状态，随时可以接受新的任务。」
