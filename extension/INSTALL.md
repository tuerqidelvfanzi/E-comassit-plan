# 电商助手 · 浏览器插件（演示版 v0.6）

## 安装（Chrome / Edge）

1. 从 B 站「工作台」或「设置」下载 ZIP，解压到任意目录（文件夹内必须有 `manifest.json` 和 `icons/`）。
2. 打开 `chrome://extensions`（Edge：`edge://extensions`）。
3. 开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的 `extension` 文件夹（或 ZIP 解压根目录）。

安装成功后，工具栏应显示蓝色「电商助手」图标；点击可打开三栏 Popup（连接 / 采集 / 发布）。

## 配置（本地全栈）

| 项 | 示例 |
|----|------|
| 后台地址 | `http://localhost:3004` |
| API 地址 | `http://127.0.0.1:8080` |
| 插件令牌 | B 站 **设置** 页复制 `psa_…` |

在 Popup **连接** 页点击「测试 API 连接」。

## 发布填表（v0.6）

1. B 站 **发布中心** 创建任务 → **生成填表**。
2. 打开 Shopee / TikTok / 淘宝 **卖家后台「新建商品/草稿」** 页。
3. 插件 Popup → **发布** →「从 API 拉取填表数据」→ **填入当前卖家页**。
4. 页面**左侧**出现 **Mock 填表预览面板**（完整载荷：标题、价格、SKU、物流等）。
5. 若平台 DOM 可匹配，会同时尝试填入标题/价格/库存等字段（Toast 提示结果）。
6. 卖家页右下角 **「电商助手」** 浮动按钮可再次打开预览面板。

## 说明

- **Mock 预览面板** 为演示 UI，正式版将按面板字段自动填表。
- DOM 选择器随平台改版可能失效，以预览面板为准核对。
- 采集仍支持 1688 / 淘宝 / 天猫详情页。
