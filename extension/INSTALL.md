# 电商助手 · 浏览器插件 v3.1

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目中的 `extension` 文件夹

安装成功后，工具栏显示插件图标。

## 功能

### 采集商品
- 支持平台：1688 / 淘宝 / 天猫 / 拼多多 / 京东
- 点击商品详情页右侧悬浮按钮采集
- 采集数据：标题、价格、图片、SKU、属性
- 一键上传到采集箱

### 发布填表
- 支持平台：Shopee / TikTok 卖家后台
- 从发布中心拉取填表数据
- 自动填充标题/价格/库存

### 配置
| 项 | 示例 |
|----|------|
| 后台地址 | `http://localhost:5173` |
| API 地址 | `http://127.0.0.1:8080` |
| 插件令牌 | 网页端设置页获取 |

## 测试步骤

1. 启动后端 `cd api && npm run dev`
2. 启动前端 `cd web && npm run dev`
3. 打开淘宝/1688商品详情页
4. 点击右侧粉红色悬浮按钮采集
5. 查看采集结果，可复制或上传

## 注意

- 首次使用需配置API地址和令牌
- 部分平台DOM选择器可能需调整
- 遇到问题查看浏览器控制台日志
