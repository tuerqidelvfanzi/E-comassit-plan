## 0. 启动环境

```bash
# 终端 1 — API（默认 8080）
cd api && npm install && npm run dev

# 终端 2 — Web（默认 3004，代理 /api/v1）
cd web && npm install && npm run dev
```

浏览器打开：**http://localhost:3004** → 登录 → 进入 `/app`。

> 仅静态页（GitHub Pages）：无 API 时自动走 `v2ApiLocal` 浏览器 Mock。

## 1. 处理层 · 源平台竞品与找同类（F-P-INS01）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1.1 | 侧栏 **竞品分析** | 页眉说明「在**源平台**分析…」 |
| 1.2 | 源平台选 **淘宝**，关键词 `儿童 T恤 纯棉` → **新建分析任务** | 任务列表出现新项 |
| 1.3 | 选中任务 → **运行分析（Mock）** | 状态 `done` |
| 1.4 | 切 Tab **找同类/类似款** | 列表 3 条 Mock 链接，标注月销 |
| 1.5 | 切 Tab **品类洞察** | GMV/CTR、热词、样例标题 |

**需求核对**：找同类发生在源平台（淘宝），不是 B 站商品库搜索。

## 3. 处理层 · 工作台（F-P-R01、六段 SKU、越南 20 字、13 步）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 3.1 | 采集箱任选商品 → **处理工作台** | 左栏原始标题/图/源链接 |
| 3.2 | 目标市场 **越南 Shopee**，模板 **T恤** → **运行管线** | 双指标标题、SKU 表 |
| 3.3 | 编辑标题超过 20 字 | 红色/警告：字符超限 |
| 3.4 | 查看 SKU 表 | `BF-0001-PR-WH-S+B`、`+H` 列 |
| 3.5 | **越南 Shopee 13 步** 清单 | 可勾选，部分预填 done |
| 3.6 | **双栏对比** | 左原始 / 右处理后 |
| 3.7 | **图片处理** 按钮 | Mock 提示（消除/翻译） |
