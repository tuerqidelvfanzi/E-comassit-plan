# 业务流程细化设计 v2

> 版本：v2.0 - 日期：2026-05-30

---

## 1. 业务流程全景图

```
源平台（竞品分析+采集） → 处理（AI优化） → 目标平台（发布）
    │                        │                     │
 淘宝/拼多多/            标题优化/SKU生成/       Shopee越南/
 Shopee/TikTok           价格计算/违禁检测       TikTok泰国
```

---

## 2. 完整业务流程

### 步骤1: 竞品分析（在源平台）

目的：在源平台找同类爆款，分析标题/价格/款式

动作：
- 在淘宝搜索"T恤"
- 分析TOP100标题关键词
- 找出热门款式和价格区间
- 生成竞品分析报告

### 步骤2: 商品采集

目的：根据竞品分析结果，采集要上品的商品

动作：
- 根据分析结果在源平台找相似商品
- 采集商品数据（标题/价格/图片/SKU）
- 加入采集箱

### 步骤3: AI处理优化

目的：对采集的商品进行本地化处理

动作：
- 选择目标平台（越南/泰国/菲律宾）
- 选择类目模板（男装/女装/童装等）
- 运行AI处理（标题优化/SKU生成/价格计算）
- 生成处理结果

### 步骤4: 发布到目标平台

目的：将处理后的商品发布到目标平台

动作：
- 预览确认
- 插件填表
- 完成发布

---

## 3. 竞品分析详解

### 3.1 源平台的双重角色

| 平台 | 竞品分析 | 采集来源 |
|------|----------|----------|
| 淘宝 | 分析国内爆款标题风格 | 商品数据 |
| 拼多多 | 分析低价爆款 | 商品数据 |
| Shopee越南 | 分析越南本地爆款 | 可采集越南商品 |
| TikTok泰国 | 分析泰国视频爆款 | 可采集TikTok商品 |

### 3.2 竞品分析维度

- 标题分析：TOP100关键词提取
- 价格分析：价格区间分布
- 款式分析：颜色/尺码/风格趋势
- 销量分析：GMV/CTR估算

---

## 4. 数据流转

```
源平台商品列表
    │
    ▼
竞品分析 ──> 分析报告（标题词/价格/款式）
    │
    ▼
采集目标商品 ──> RawProduct
    │
    ▼
AI处理（参考分析报告） ──> ProcessedProduct
    │
    ▼
目标平台发布
```

---

## 5. 采集来源分类

| 采集类型 | 说明 |
|----------|------|
| 竞品采集 | 采集同类爆款，用于分析 |
| 商品采集 | 采集要上品的商品 |
| 批量采集 | 批量采集榜单TOP N |

## 6. 总结

### v1 vs v2 对比

| 项目 | v1流程 | v2流程 |
|------|--------|--------|
| 竞品分析 | 无 | 有（在源平台分析） |
