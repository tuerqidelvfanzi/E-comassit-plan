## 2. 详细任务清单

### T1: 插件采集（1688/淘宝）
**文件**: extension/
**功能**:
- MV3 Chrome Extension
- 悬浮按钮采集
- JSON→DOM分层提取
- 输出 NormalizedProduct

**验收标准**:
- [ ] 能从1688详情页采集数据
- [ ] 能从淘宝详情页采集数据
- [ ] 数据字段完整（标题/价格/图片/SKU/属性）

### T2: 采集箱基础功能
**文件**: web/src/pages/InboxPage.tsx
**功能**:
- 商品列表展示
- 分页/筛选/排序
- 来源标记
- 批量操作

**验收标准**:
- [ ] 显示采集的商品列表
- [ ] 支持按来源筛选
- [ ] 支持删除操作

### T3: 标题改写（越南≤20字）
**文件**: web/src/components/TitleOptimizer.tsx, api/src/title/
**功能**:
- 关键词提取
- 语义压缩
- 越南语翻译
- 字符截断（≤20）

**验收标准**:
- [ ] 输入中文标题，输出越南语≤20字符
- [ ] 字符计数准确

### T4: 五段SKU编码生成
**文件**: shared/src/sku/
**功能**:
- SKU矩阵生成（颜色×尺码）
- 五段编码 {PREFIX}-{SEQ}-{SIDE}-{COLOR}-{SIZE}
- 白色钩子生成

**验收标准**:
- [ ] 生成正确格式的SKU编码
- [ ] 白色钩子SKU格式正确

### T5: 违禁词检测
**文件**: shared/src/validation/
**功能**:
- 品牌词检测
- 国内标识检测
- 虚假宣传检测
- 面料一致性检测

**验收标准**:
- [ ] 检测Nike/Adidas等品牌词
- [ ] 检测"全国包邮"等国内标识
- [ ] 警告/阻断策略生效

### T6: 越南Shopee填表
**文件**: extension/src/content/publish/
**功能**:
- DOM定位填表
- 截图验证
- 失败重试

**验收标准**:
- [ ] 能填写越南Shopee表单
- [ ] 发布状态追踪

### T7: 36种主题系统
**文件**: web/src/lib/theme.ts, web/src/styles/themes.css
**功能**:
- 36种预设主题
- 分类分组展示
- 实时切换
- 自定义CSS

**验收标准**:
- [ ] 36种主题全部可切换
- [ ] 分类标签正确
- [ ] 主题实时生效

## 3. 开发顺序建议

```
第一轮（可并行）:
├─ T1 插件采集
├─ T7 主题系统（独立）
└─ T5 违禁词检测（独立）

第二轮:
├─ T2 采集箱 ← T1
├─ T4 SKU编码 ← T2
└─ T12 模板系统（独立）

第三轮:
├─ T3 标题改写 ← T2, T5
└─ T6 越南填表 ← T3, T4, T5

第四轮（收尾）:
└─ 集成测试 + 验收
```
