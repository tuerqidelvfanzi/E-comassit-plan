# 标题优化步骤详细设计

> 版本：v1.0 - 日期：2026-05-30
> 依据：越南Shopee标题规则（≤20字符）+ 调研资料

---

## 1. 越南站标题优化流程

### 1.1 标题优化完整步骤

```
原始标题 → 关键词提取 → 规则校验 → 语义压缩 → 本地化翻译 → 违禁词检测 → 优化后标题
```

### 1.2 详细步骤说明

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 原始标题输入 | 接收淘宝/拼多多原始标题 |
| 2 | 关键词提取 | 提取：品类词、属性词、特色词、品牌词 |
| 3 | 字数统计 | 统计中文字符数、越南语字符数 |
| 4 | 汉字压缩 | 汉字≥10字时触发压缩警告 |
| 5 | 越南语翻译 | 翻译为越南语 |
| 6 | 字符截断 | 确保≤20字符 |
| 7 | 违禁词检测 | 检查品牌词、国内标识 |
| 8 | 输出结果 | 生成优化后标题 |

## 2. 标题优化步骤详情

### 步骤1：原始标题输入

**输入示例**：
```
可爱蓝色小熊熊图案卡通印花休闲百搭纯棉短袖T恤儿童韩版
```

### 步骤2：关键词提取

**提取规则**：
| 关键词类型 | 示例 | 保留优先级 |
|------------|------|------------|
| 品类词 | T恤、上衣、裙子 | 必须 |
| 材质词 | 纯棉、棉质、聚酯纤维 | 高 |
| 特色词 | 可爱、韩版、卡通 | 中 |
| 人群词 | 儿童、男童、女童 | 高 |
| 颜色词 | 蓝色、白色、黑色 | 高 |
| 风格词 | 休闲、百搭、运动 | 中 |

### 步骤3：字数统计

**统计规则**：
- 中文字符：每个汉字算1个字符
- 越南语字符：每个越南语字母算1个字符
- 总字符数 = 中文字符数 + 越南语字符数

**示例**：
```
可爱蓝色小熊熊图案卡通印花休闲百搭纯棉短袖T恤儿童韩版
字符数：37字符
```

### 步骤4：汉字压缩（关键步骤）

**压缩规则**：
| 汉字数量 | 处理方式 |
|----------|----------|
| ≤9字 | 正常保留 |
| 10-15字 | 提示警告，可保留 |
| >15字 | 必须压缩 |
| >20字 | 强制压缩 |

**压缩策略**：
1. 删除重复词（如"可爱"出现2次只保留1个）
2. 删除无意义词（如"的"、"了"）
3. 使用缩写（如"卡通"保持）
4. 删除空格
5. 优先保留：品类词+颜色词+材质词

**压缩示例**：
```
原文：可爱蓝色小熊熊图案卡通印花休闲百搭纯棉短袖T恤儿童韩版
压缩后：蓝色小熊熊T恤纯棉儿童
越南语：A04 Gấu Xanh Thun Cotton Bé 20 Ký Tự
```

### 步骤5：越南语翻译

**翻译规则**：
| 中文 | 越南语 |
|------|--------|
| T恤 | áo thun / áo phông |
| 纯棉 | cotton 100% / vải cotton |
| 儿童 | trẻ em / bé |
| 男童 | bé trai |
| 女童 | bé gái |
| 蓝色 | xanh dương / xanh |
| 白色 | trắng |
| 可爱 | dễ thương / ngộ nghĩnh |

### 步骤6：字符截断（≤20字符）

**截断规则**：
1. 从后向前删减
2. 优先删除风格词
3. 保留：品类词+颜色词+人群词

**截断示例**：
```
翻译后：A04 Gấu Xanh Thun Cotton Bé Trai Ngộ Nghĩnh
字符数：42字符
截断后：A04 Gấu Xanh Thun Cotton Bé
字符数：24字符 - 仍超4字符
再次截断：A04 Gấu Thun Cotton Bé
字符数：20字符 ✓
```

### 步骤7：违禁词检测

**检测清单**：
| 类型 | 示例 |
|------|------|
| 品牌词 | Nike, Adidas, Gucci, Apple, Samsung |
| 国内标识 | 中国制造、Made in China、3C认证 |
| 虚假宣传 | 第一、最好、最高、100%纯棉（除非属实） |

### 步骤8：输出结果

**最终输出**：
```json
{
  "originalTitle": "可爱蓝色小熊熊图案卡通印花休闲百搭纯棉短袖T恤儿童韩版",
  "optimizedTitleVn": "A04 Gấu Thun Cotton Bé",
  "charCount": 20,
  "cjkCharCount": 12,
  "warnings": ["汉字数量12字，建议压缩到9字以内"],
  "keywords": {
    "preserved": ["T恤", "纯棉", "儿童", "蓝色", "小熊"],
    "removed": ["可爱", "卡通", "图案", "休闲", "百搭", "韩版"]
  },
  "bannedWords": [],
  "processedAt": "2026-05-30"
}
```
