## 一、系统定位

### 核心用户
**跨境电商运营**：将中国商品搬运到东南亚平台，或国内商家优化自己的店铺

### 系统目标
- 单商品上品耗时：30-60分钟 → ≤5分钟
- 批量搬品：规则确定 + AI辅助
- 多市场：一套数据发布多个平台

## 三、核心业务逻辑（重要修正）

### 3.1 电商AI助手 - 标题优化流程（通用）

```
┌─────────────────────────────────────────────────────────────┐
│                     采集层（任意源平台）                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  天猫  │  淘宝  │  抖音  │  1688  │  拼多多  │  京东  │
│   ↓       ↓       ↓       ↓       ↓         ↓            │
│                  统一商品数据                               │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                     处理层（标题优化）                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 关键词提取   │  品类词、材质词、颜色词、人群词        │
│         ↓                                                   │
│  2. 汉字压缩     │  汉字≤10字（越南站要求）                 │
│         ↓                                                   │
│  3. 本地化翻译   │  中→越 / 中→泰 / 中→英                  │
│         ↓                                                   │
│  4. 字符截断     │  越南≤20 / 泰国≤220 / 菲律宾≤120        │
│         ↓                                                   │
│  5. 违禁词检测   │  品牌词、国内标识                        │
│                                                             │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                     发布层（任意目标平台）                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  越南Shopee  │  泰国TikTok  │  菲律宾Shopee  │  天猫/淘宝  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**关键特性**：
- ✅ **采集来源**：任意平台（天猫、淘宝、抖音、1688、拼多多、京东等）
- ✅ **优化处理**：通用处理流程，根据目标平台适配规则
- ✅ **发布目标**：任意平台（Shopee越南、Shopee泰国、TikTok、菲律宾、甚至回写天猫）

## 四、两个功能的区别

| 维度 | 电商AI助手标题优化 | 天猫标题优化工具 |
|------|-------------------|-----------------|
| **采集来源** | 天猫、淘宝、抖音、1688、拼多多、京东等 | 仅天猫/淘宝（用户已有商品） |
| **核心处理** | 压缩+翻译（≤20/220字符） | 搜索词分析+AI生成新标题 |
| **输出语言** | 目标市场本地语言 | 中文（天猫商家自用） |
| **发布目标** | 越南Shopee/泰国TikTok/菲律宾/天猫回写 | 天猫后台（自用） |
| **用户** | 跨境电商运营 | 国内天猫商家 |
