# REQ-A: V3.0 收尾优化

> **轨道**: A | **目标**: 清理 V3.0 残留 + 强化测试基础设施
> **创建日期**: 2026-06-02 | **状态**: 📋 需求阶段

---

## 1. 背景

V3.0 主题系统升级后，存在以下遗留问题：

### 1.1 主题系统残留
- `web/src/lib/theme.ts`（旧版）仍在使用 12 主题
- `web/src/styles/themes.css` 部分硬编码颜色
- 36 主题被精简为 4（已修复），但代码中可能残留旧引用

### 1.2 测试基础设施不足
- 无视觉回归测试（主题切换后无法截图对比）
- 无 ESLint 规则强制 CSS 变量使用
- 无移动端响应式测试
- 无性能基线

## 2. 目标

清理 V3.0 升级遗留 + 补齐测试基础设施，让"防错管道"真正可执行。
