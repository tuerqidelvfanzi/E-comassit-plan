# REQ-B: V3.1 主题系统增强

> **轨道**: B | **目标**: 主题市场 + 预览图 + 动画切换
> **创建日期**: 2026-06-02 | **状态**: 📋 需求阶段

---

## 1. 背景

V3.0 主题系统已实现 4 主题包 + 配色微调器。但用户反馈：

- 主题卡只能看到当前色彩，没有"整页预览"
- 主题切换是瞬间切换，缺少过渡动画
- 没有社区/市场机制，用户无法分享自己的配色

## 2. 目标

让主题系统从"可用"升级为"好玩"。

## 4. 数据结构

```typescript
interface ThemePackage {
  id: string;            // UUID
  name: string;          // 展示名
  author: string;        // 创作者
  version: string;       // semver
  basePreset: string;    // 派生的预设
  colors: ColorScheme;   // 10 字段
  visualStyle: VisualStyle;
  density: Density;
  radius: Radius;
  spacing: Spacing;
  shadow: Shadow;
  motion: Motion;
  createdAt: number;
  thumbnail?: string;    // base64 预览图
}
```

## 5. UI/UX 要求

- 主题市场页：网格布局 + 搜索/筛选
- 导入/导出：拖拽上传 + 进度条
- 预览图：600×400 PNG，可选 GIF
