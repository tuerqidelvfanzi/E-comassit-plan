## 1. 竞品深度分析

### 1.1 店八方 vs 我们的AI助手

#### 1.1.1 功能对比

| 功能 | 店八方 | AI助手 | 差距 |
|------|--------|--------|------|
| SKU处理 | 手动填写 | 自动五段编码 | 超越 |
| 价格计算 | 手动倍率 | 自动+规则校验 | 超越 |
| 标题优化 | 简单翻译 | AI语义优化 | 超越 |
| 违禁词检测 | 无 | 品牌+国内标识 | 超越 |
| 模板系统 | 固定模板 | 累积式品类模板 | 超越 |

#### 1.1.2 店八方核心痛点

1. 规则定制难 - 无法自定义SKU编码规则
2. SKU处理繁琐 - 颜色尺码需要手动匹配
3. 图片处理效率低 - 翻译需要排队
4. 价格策略不灵活 - 无法按市场差异化

#### 1.1.3 我们的机会点

1. 智能SKU生成 - 五段编码一键生成，减少80%操作时间
2. 违禁词自动检测 - 标题/图片双重检测
3. AI标题优化 - 语义压缩+翻译，解决越南20字限制
4. 规则可配置 - 用户可自定义倍率、模板、违禁词库

## 2. 东南亚平台深度规则

### 2.1 越南 Shopee

#### 标题规则
- 限制：不超过20字符（严格）
- 规则：不能包含表情/特殊字符/其他平台名称
- 汉字需翻译或压缩
- 品牌名需授权或删除

#### 图片规则
- 数量：9张（第一张为主图）
- 尺寸：800x800像素或1000x1000像素（1:1或4:5）
- 格式：JPG/PNG，最大5MB
- 要求：第一张必须白底，不能有水印/LOGO/价格

#### 价格规则
- 倍率：通常3-3.5倍
- 计算公式：shopee_price = 原价 x 3.5
- 最低价：建议不低于15000 VND

#### 库存规则
- 建议：50-100件
- 最低：10件
- 最高：无限制（建议不超过1000）

### 2.2 泰国 TikTok Shop

#### 标题规则
- 限制：不超过220字符
- 风格：短视频风、年轻化
- 可使用emoji
- 参考同行爆款标题

#### 图片规则
- 主图：5张以上（必须）
- 详情图：建议4张固定顺序
- 尺寸：1:1 (800x800px) 或 4:5
- 中文必须翻译

#### 价格规则
- 倍率：通常2-2.5倍
- 计算公式：tiktok_price = 原价 x 2.5
- 注意：泰国消费者价格敏感，需要包邮策略

### 2.3 菲律宾 Shopee

#### 标题规则
- 限制：不超过120字符
- 语言：菲律宾语/英语混合
- 菲律宾人喜欢英语标题

#### 价格规则
- 策略：低价策略为主
- 建议固定低价：PHP 299/399/499
- 不要超过PHP 999

### 2.4 印尼 Shopee

#### 标题规则
- 限制：不超过120字符
- 语言：印尼语
- 宗教相关禁忌

#### 认证要求
- SNI认证（部分类目强制）
- BPOM认证（食品/化妆品）
- 宗教认证（清真食品）

## 3. SKU编码详解

### 3.1 五段编码格式

格式：{PREFIX}-{SEQUENCE}-{SIDE}-{COLOR}-{SIZE}

示例：BF-0001-PR-WH-S

### 3.2 各字段说明

| 字段 | 位置 | 说明 | 示例 |
|------|------|------|------|
| PREFIX | 1-4位 | 店铺名前缀 | BF、MY、KD |
| SEQUENCE | 5-8位 | 序号0001-1000 | 0001、0002 |
| SIDE | 9-10位 | 图案位置 | P/R/PR |
| COLOR | 11-12位 | 颜色代码 | WH/BK/RD |
| SIZE | 13位+ | 尺码 | S/M/L/XL |

### 3.3 颜色代码表

| 颜色 | 中文 | 代码 |
|------|------|------|
| 白色 | 白色 | WH |
| 黑色 | 黑色 | BK |
| 红色 | 红色 | RD |
| 蓝色 | 蓝色 | BL |
| 绿色 | 绿色 | GR |
| 黄色 | 黄色 | YL |
| 粉色 | 粉色 | PK |
| 紫色 | 紫色 | PU |
| 橙色 | 橙色 | OR |
| 灰色 | 灰色 | GY |
| 棕色 | 棕色 | BN |
| 米色 | 米色 | BE |

### 3.4 尺码代码表

| 尺码 | 代码 |
|------|------|
| 特小 | XXS |
| 小码 | XS |
| 中码 | S |
| 大码 | M |
| 加大 | L |
| 双加大 | XL |
| 三加大 | XXL |
| 自由码 | FM |

### 3.5 白色钩子

触发条件：单款式商品（只有一种颜色）

配置：
- SKU：{PREFIX}-9999-P-WH-{SIZE}
- 价格：固定400
- 库存：固定5
- 重量：固定220g

## 4. 品类深度攻略

### 4.1 服装类（核心品类）

#### SKU矩阵设计

基础SKU矩阵：5-10种颜色 x 5-7种尺码 = 25-70个SKU

示例（5色x6码）：
- 白色/黑色/红色/蓝色/粉色 x S/M/L/XL/XXL/XXXL

白色钩子策略：
- 触发条件：单款式商品
- SKU：{PREFIX}-9999-P-WH-{SIZE}
- 价格：400，库存：5，重量：220g

#### 越南站标题优化（20字符）

压缩策略：
1. 删除重复词
2. 保留核心词
3. 使用缩写
4. 删除空格

示例：
- 原文：可爱蓝色小熊图案卡通印花休闲百搭纯棉短袖T恤儿童
- 压缩：A04蓝熊卡通纯棉T恤

#### 泰国站标题优化

结构：热门词 + 品类词 + 特色词 + 规格词

示例：
[emoji] + เสื้อยืดผ้าฝ้าย + ลายการ์ตูนน่ารัก + ฟรีไซส์

### 4.2 灯具类

#### SKU配置维度

- 维度1：功率（24W/36W/48W）
- 维度2：色温（暖光/白光/自然光）
- 维度3：控制方式（开关/遥控/APP）

SKU矩阵：3 x 3 x 3 = 27个SKU

### 4.3 母婴用品类

#### 儿童服装尺码体系

- 0-2岁：52/59/66/73/80
- 2-6岁：90/100/110/120
- 6-14岁：130/140/150/160

#### 特殊要求

- 材质：A类面料、无荧光剂
- 认证：材质安全认证
- 图片：安全性、认证标识展示

### 4.4 美妆个护类

#### 认证要求

- 印尼：BPOM认证
- 泰国：Thai FDA认证
- 越南：卫生部认证

#### 图片要求

- 成分说明
- 使用效果
- 认证标识
- 不能夸大功效
- 不能使用医疗用语

## 5. AI技术应用深度分析

### 5.1 标题优化AI

#### 多语言翻译API选择

- Google Translate（通用，质量一般）
- DeepL（欧洲语言强）
- GPT-4/Gemini（语义理解强，推荐）
- 阿里翻译（中文相关强）

#### 越南站标题Prompt设计

角色：越南Shopee电商上品专家，精通越南语

任务：将中文标题优化为越南语，限制20字符

规则：
1. 字符数严格20字符
2. 必须包含品类词
3. 优先保留特色词
4. 删除重复词
5. 可使用缩写

### 5.2 图片处理AI

#### OCR文字识别

- PaddleOCR（中文强，开源，推荐）
- Tesseract OCR（开源免费）
- 百度OCR（中文强）

#### 图片翻译

- 创客贴/图怪兽（模板化）
- 象寄翻译（电商专用）
- Google Translate API

#### 消除笔

- Remove.bg（去背景强）
- cleanup.pictures（免费）
- 腾讯AI消除笔
- 阿里图像修复

### 5.3 违禁词检测AI

#### 检测类型

品牌侵权词：Nike, Adidas, Disney, LV, Gucci, Chanel, 爱马仕, 苹果, 三星, 华为, NASA

国内标识词：3C认证、中国制造、Made in China、发货地、包邮

虚假宣传词：最高级词汇、绝对化词汇、医疗用语

#### 面料检测规则

- 标题含"棉" - 属性必须含棉
- 混纺需标注比例
- 功能宣称需有依据

## 6. 技术实现建议

### 6.1 采集模块技术方案

#### 分层抓取架构

L1 JSON (最快) -> L2 JSON-LD (结构化) -> L3 API接口 (需认证) -> L4 DOM解析 (兜底)

#### 反爬应对策略

基础策略：
- 随机延迟：250-2500ms
- User-Agent轮换
- 请求头随机化
- 失败重试（3次）

进阶策略：
- IP代理池
- Cookie管理
- 分布式采集
- 验证码处理

### 6.2 发布模块技术方案

#### 填表技术选型

方案1：Content Script DOM操作
- 优点：通用性强
- 缺点：依赖页面结构
- 适用：临时应急

方案2：Open API对接
- 优点：稳定效率高
- 缺点：需要授权
- 适用：官方合作

方案3：ADS Power指纹浏览器
- 优点：模拟人工
- 缺点：成本高
- 适用：账号管理

### 6.3 AI模块技术架构

#### 模型选择建议

- 开发测试：GPT-3.5
- 生产环境：GPT-4（标题优化）
- 翻译任务：DeepL/Gemini
- 本地部署：Qwen/LLaMA

#### Token成本优化

1. Prompt优化 - 精简指令
2. Few-shot示例
3. 结果缓存

## 7. 运营策略建议

### 7.1 上品节奏

新店期（0-3个月）：
- 每天上架：10-20个
- 策略：低价引流、积累评价

成长期（3-6个月）：
- 每天上架：5-10个
- 策略：打造爆款、集中资源

稳定期（6个月+）：
- 每天上架：3-5个
- 策略：利润优化、复制模式

### 7.2 定价策略

越南站：
- 倍率区间：3.0-4.0倍
- 建议倍率：3.5倍
- 公式：越南价 = 原价 x 3.5

泰国站：
- 倍率区间：2.0-3.0倍
- 建议倍率：2.5倍
- 公式：泰国价 = 原价 x 2.5

### 7.3 违禁规避

标题违禁词：
- 最高级词汇：第一/最好/最强
- 绝对化词汇：100%/绝对/保证
- 品牌词：无授权的品牌名
- 政治/宗教词汇

图片违禁内容：
- LOGO/水印
- 价格标签
- 二维码
- 联系方式
- 其他平台标识

## 8. 风险与对策

### 技术风险

| 风险 | 影响 | 对策 |
|------|------|------|
| 平台反爬升级 | 采集失败 | 代理池+分布式 |
| DOM结构变更 | 填表失效 | selector映射表 |
| API接口变更 | 功能异常 | 版本控制+监控 |
| LLM服务不可用 | 处理中断 | 多模型备选 |

### 运营风险

| 风险 | 影响 | 对策 |
|------|------|------|
| 账号封禁 | 发布中断 | 多账号+限速 |
| 商品被下架 | 损失流量 | 违禁词检测 |
| 侵权投诉 | 法律风险 | 品牌库+审核 |
| 平台政策变更 | 规则失效 | 及时跟踪 |
