## 3. 程序员社区调研

### 3.1 CSDN/掘金热门话题

**标题模式分析**：

| 话题类型 | 示例标题 |
|----------|----------|
| 采集技术 | 「Shopee商品数据采集实战」「TikTok Shop API对接」 |
| 上品技巧 | 「Shopee上品避坑指南」「TikTok选品技巧」 |
| 工具推荐 | 「东南亚电商工具清单」「店八方使用心得」 |

**核心观点提炼**：

1. **反爬是关键**
   - IP封禁是最大痛点
   - 需要代理池支持
   - 随机延迟是基础

2. **上品效率**
   - 批量操作是刚需
   - 模板化能大幅提升效率
   - 人工检查不可少

3. **本地化重要性**
   - 翻译质量直接影响转化
   - 本地化不仅是语言
   - 文化适配很关键

### 3.2 社区反馈总结

**优点**：
- 店八方等工具基本功能完善
- 批量上品能提升效率
- 图片翻译功能实用

**痛点**：
- 图片翻译质量不稳定
- SKU变体处理复杂
- 多平台规则不同
- 封号风险高

**期望**：
- 更智能的标题优化
- 自动化的违禁词检测
- 批量处理能力
- 多平台统一管理

## 5. 品类SKU模式研究

### 5.1 服装类（多规格）

**SKU矩阵特点**：
- 颜色×尺码 = SKU数量
- 5色×6码 = 30个SKU
- 白色钩子是通用占位

**上品技巧**：
- 先确定主色
- 尺码按国际标准
- 颜色编码统一

**时间成本**：
- 设置SKU：10-15分钟
- 批量设置：5-10分钟

### 5.2 家居类（中规格）

**SKU变体特点**：
- 规格组合为主
- 数量3-10个
- 尺寸/颜色/材质

**上品技巧**：
- 规格参数清晰
- 对比表格有用
- 尺寸说明详细

**时间成本**：
- 设置SKU：5-10分钟
- 批量设置：3-5分钟

### 5.3 定制类（少规格）

**SKU特点**：
- 支持自定义参数
- SKU数量少
- 需要用户输入

**上品技巧**：
- 参数描述清晰
- 样品图必备
- 咨询引导重要

**时间成本**：
- 设置SKU：15-20分钟
- 定制沟通：额外时间

## 7. AI应用最佳实践

### 7.1 标题优化

**AI应用场景**：
- 多语言翻译
- 关键词提取
- SEO优化
- 本地化表达

**Prompt设计要点**：
```
角色设定 → 品类知识 → 平台规则 → 输出格式 → 约束条件
```

**效果评估**：
- 字符数准确
- 关键词保留
- 违禁词过滤
- 可读性检查

### 7.2 图片处理

**AI应用场景**：
- 文字识别（OCR）
- 翻译覆盖
- 水印去除
- 尺寸调整

**工具选择**：
- 消除笔：Remove.bg、Inpaint
- 翻译：Google Translate API、AI翻译
- 尺寸：Sharp/Pillow

### 7.3 描述生成

**AI应用场景**：
- 短描述（越南站20字）
- 详细描述
- FAQ生成

**结构化输出**：
```json
{
  "shortDesc": "20字内",
  "mainPoints": ["要点1", "要点2"],
  "specs": {"材质": "棉", "尺寸": "均码"},
  "faq": [{"q": "问题", "a": "回答"}]
}
```

## 8. 行业经验总结

### 8.1 上品效率提升

| 方法 | 效果 | 实现难度 |
|------|------|----------|
| 模板化 | +50%效率 | 低 |
| 批量操作 | +30%效率 | 中 |
| AI辅助 | +60%效率 | 高 |
| RPA自动化 | +80%效率 | 高 |

### 8.2 避坑指南

1. **标题**
   - ❌ 夸大宣传（最高/第一）
   - ❌ 绝对化词汇（100%纯棉）
   - ❌ 品牌词（除非授权）

2. **图片**
   - ❌ 价格标签
   - ❌ 水印LOGO
   - ❌ 敏感内容

3. **SKU**
   - ❌ 库存为0
   - ❌ 价格异常
   - ❌ 规格不符

4. **描述**
   - ❌ 联系方式
   - ❌ 外链
   - ❌ 竞品词

### 8.3 成功案例特征

**高销量商品特点**：
1. 主图清晰，白底优先
2. 标题关键词精准
3. 价格有竞争力
4. 评论数量多
5. 详情页专业

**上品节奏**：
- 每天上架10-20个新品
- 持续优化老品
- 关注竞品动态
