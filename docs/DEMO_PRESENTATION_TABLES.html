演示讲解 · 业务流程三表

面向运营与业务评审 · 本平台 = 电商助手后台 · 供货网站 = 淘宝/1688 等用来选款、采集的页面 · 卖货平台 = Shopee/TikTok 等卖家后台用来上架的页面

选品洞察页的数据从哪来？（讲解时务必说清）
  • 竞品分析页：运营填写「在哪个供货网站、搜什么关键词」，点「运行分析」后得到一份报告（热卖程度、点击率、热词、价格带、样例标题、类似在售款列表）。当前演示为示例数据，正式版需对接真实抓取或第三方数据。
  • 选品洞察页：是只读汇总看板。「关联竞品报告」来自已经跑完的竞品分析任务；页上的热词排行、成交档位等，演示里部分是固定示例，尚未与每一次分析结果严格联动。
  • 正确顺序：先竞品分析出报告 → 再选品洞察看汇总；不能只在选品洞察里「找同款」。要把结论用于加工：在商品加工工作台里选择「带入本次竞品结论」。

1.2 分步演示明细

流程 步 操作路径 这一步要说明的业务点 数据说明（给观众） 讲解话术提示
流程一 · 业务主线
一1登录 → 工作台进入本公司运营后台，不是打开淘宝或 Shopee 网页登录后看到采集量、能力说明等总览强调「本平台」与供货站、卖货平台的区别
一2工作台 → 竞品分析（可选）在供货网站语境下看关键词竞争情况演示为示例分析报告选品发生在供货网站侧，不是搜自己仓库
一3竞品分析页内查看「类似在售款」列表示例链接，正式版对应供货站搜索结果找同款仍在供货站结果里
一4竞品分析 → 链接直采 → 采集箱定下款式后，把商品收进采集箱粘贴商品链接后预览再入库；也可改用插件采集采集箱是「待加工商品清单」
一5采集箱 → 商品加工按规则与模板改标题、SKU、图片等智能改写为演示输出，保存后写入商品资料对应 ERP 里手工编标题、SKU、九图
一6商品加工页内越南短标题、六段 SKU、九图位、上架检查清单字数与违禁为系统校验；图片处理按钮为演示逐项指给观众看
一7商品加工 → 发布中心生成给浏览器插件使用的填表数据「生成填表」为真实业务能力；不是插件直接连卖货平台后台账号数据先在本平台准备好
一8发布中心 → 设置 → 插件连接 → 插件发布在卖货平台卖家后台新建商品页，由插件填入字段需先在设置里复制连接令牌设置 → 连接 → 打开 Shopee 卖家页 → 发布
一9回到工作台收尾：回顾已具备的能力模块首页能力列表对照里程碑说明
流程二 · 选品洞察专场
二1登录 → 竞品分析新建「供货网站 + 关键词」分析任务演示环境立即生成示例报告说明分析的是外部市场，不是内部库存
二2竞品分析 · 品类洞察看热卖程度、点击率、热词、价格带来自当前这一次分析报告切换「品类洞察」标签
二3竞品分析 · 找同类看类似在售款与链接示例商品列表切换「找同类/类似款」
二4竞品分析 → 选品洞察跨多次分析看热词档位、报告列表报告列表依赖已完成的分析；部分图表为演示固定样例须先跑完分析，否则报告列表为空
二5选品洞察 → 竞品分析从汇总回到某一次具体分析点击关联报告报告可来回跳转
二6竞品分析 → 商品加工把竞品结论带入本款加工的「临时说明」加工页下拉选择本次分析研究结论进入写标题、写描述时的上下文
流程三 · 采集入库专场
三1设置 → 插件 · 连接插件与本公司后台建立连接复制令牌、测试连通采集和发布都依赖这一步
三2插件 · 采集（在供货网站商品页）从 1688/淘宝等详情页抓取商品信息按统一商品字段上传打开供货站商品页再点采集
三3插件采集 → 采集箱确认新商品已进入待加工列表可筛选、导出采集箱出现新行
三4采集箱批量筛选、导出列表为已入库商品演示筛选与导出
三5链接直采 → 采集箱不装插件时，粘贴商品链接入库演示为模拟解析进度适合单链接试跑
三6批量采集 → 采集箱按榜单链接一次采多款演示任务进度；需登录供货站同步 Cookie看批量任务表
三7插件 · 连接把供货站登录状态同步给批量任务用演示级能力在淘宝已登录页操作同步
流程四 · 商品加工专场
四1类目模板按童装、T 恤、灯具等类目选加工策略目录展示各类模板卡片可筛「服装 A 类」
四2类目模板 → 模板管理配置颜色尺码规则、印花加价、白色引流款可新建、编辑保存打开管理页演示
四3规则库各国售价倍数、违禁词可新增规则；违禁词有默认表指违禁词区域
四4采集箱 → 商品加工进入某一商品的加工界面从列表点「编辑」选一条商品
四5商品加工挂载本次竞品分析结论依赖已完成的竞品任务竞品洞察下拉框
四6商品加工改标题、短描述、详描；校验字数与违禁智能文案为演示输出强调越南 20 字等规则
四7商品加工九张主图位；去水印/翻译为演示按钮图片任务未接真实服务商点三个图片相关按钮
四8商品加工默认重量尺寸；Shopee 上架检查清单如 220 克、常用包裹尺寸物流区 + 清单勾选
四9商品加工一键跑加工流程；双风格标题；SKU 表加工结果为演示点「运行管线」
四10商品加工保存本款修改写入商品资料保存编辑
流程五 · 发布与插件闭环
五1商品加工 → 发布中心创建发布任务并「生成填表」生成的是插件可读的一套字段；与「仅演示状态的模拟填表」不同务必点「生成填表」
五2发布中心说明：本平台生成数据 → 插件 → 卖货平台页顶说明卡片三端闭环
五3发布中心 → 平台集成多国卖货平台适配方式说明页面展示计划支持的站点路线图讲解
五4设置 → 插件 · 连接配置令牌并连接与流程三相同复制令牌 → 连接
五5发布中心 → 插件 · 发布在卖货平台卖家页拉取并填入以越南 Shopee 新建商品页为主拉取 → 填入
五6插件 · 发布（页内）左侧对照预览填了哪些字段预览为演示面板指预览与悬浮按钮
五7发布中心（可选）只看任务状态变化的「模拟填表」不写入真实卖货后台，仅演示进度与「生成填表」区分开讲
流程六 · 系统与协作
六1设置下载插件安装包、查看标准作业流程图提供安装包与说明下载插件
六2设置大模型账号、界面主题表单配置大模型与主题
六3团队成员与角色（演示为示例人员）示例数据协作预留
六4退出登录结束会话—侧栏退出
流程七 · 全功能点一遍
七—按侧栏顺序逐项打开每个菜单 1～2 分钟说明用途选品洞察建议在完成至少一次竞品分析后再打开用于验收「是否都能点到」
