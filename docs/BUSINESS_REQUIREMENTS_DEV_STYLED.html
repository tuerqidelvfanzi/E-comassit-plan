电商商品采集优化搬家系统 - 开发级需求文档


版本：v1.0 | 日期：2026-05-30


一、业务背景与目标


1.1 三个核心功能


功能说明
------------
选品从源平台采集商品数据
优化LLM+模板本地化优化
搬家浏览器插件自动填表发布

1.2 目标用户

  • 跨境买家/小微个体卖家
  • 目标市场：东南亚（越南、泰国、菲律宾、印尼）
  • 目标平台：TikTok Shop、Shopee


    • 二、完整业务流程


    选品 -> 采集 -> 优化 -> 搬家


  • **选品阶段**：从抖音商城、淘宝、拼多多等筛选爆款
  • **采集阶段**：浏览器插件采集图片(9-12张)、SKU(颜色x尺码)
  • **优化阶段**：LLM处理标题描述、价格计算、本地化翻译
  • **搬家阶段**：插件自动填表到目标平台草稿箱


    • 三、数据字段定义


    3.1 Product 接口


    字段说明：

  • id: 唯一ID
  • title: 原标题
  • description: 原描述
  • source: 来源平台(taobao|tmall|pinduoduo|1688|douyin)
  • sourceUrl: 原商品链接
  • priceCny: 原价(人民币)
  • images[]: 图片列表
  • skus[]: SKU变体列表
  • attributes[]: 属性列表
  • status: raw|processing|ready|published
  • targetLocale: 目标语言(vi-VN|th-TH|id-ID|fil-PH)
  • categoryId: 类目模板ID
  • processed: 处理结果

    • 3.2 ProductImage


  • id: 图片ID
  • url: 原图URL
  • localPath: 本地存储路径
  • type: main|detail|sku
  • sort: 排序
  • hasWatermark: 是否有水印
  • priceTag: 是否含价格标签
  • status: pending|downloaded|processed|translated

    • 3.3 ProductSku


  • id: SKU ID
  • name: SKU名称(如"红色/M码")
  • color: 颜色
  • size: 尺码
  • price: 价格
  • stock: 库存
  • skuCode: SKU编码(内部使用)

    • 3.4 ProcessedResult


  • exposure: 高曝光向输出
  • conversion: 高转化向输出
  • selectedOutput: 用户选择的输出
  • ranAt: 处理时间
  • templateId: 使用的模板ID
  • modelUsed: 使用的模型

    • 3.5 ProcessedOutput


  • title: 优化后标题
  • description: 优化后描述
  • priceLabel: 价格标签(如฿299)

  • id: 模板ID

  • language: 目标语言
  • priority: 优先级

    • 4.3 TemplateAttribute


  • key: 属性key
  • label: 显示名
  • type: text|select|boolean
  • required: 是否必填
  • options[]: 下拉选项
  • source: fixed|template|user


    • 五、页面设计


    5.1 采集箱 (InboxPage)


    **列表字段**：

  • thumb: 缩略图
  • title: 商品标题
  • source: 来源平台badge
  • priceCny: 进价
  • skuCount: SKU数量 如"10色x6码"
  • imageCount: 图片数量
  • status: 状态badge
  • actions: 编辑/删除

    • **状态筛选**：全部/待处理/处理中/可发布/已发布


    **批量操作**：批量处理/导出JSON/导出CSV


    5.2 工作台 (WorkbenchPage)


    **原始数据区**：

  • 图片轮播展示
  • SKU表格(颜色x尺码)
  • 属性key-value列表
  • 原链接入口

    • **管线配置区**：

  • 模板选择下拉框
  • 目标语言下拉框
  • 临时提示词文本框
  • 运行管线按钮
  • 处理进度条
  • 处理日志链接

    • **结果展示区**：

  • 左列：高出向

    • - 标题、价格标签

    - 描述(可折叠)

    - 使用此版本按钮

  • 右列：高转化

    • - 标题、价格标签

    - 描述(可折叠)

    - 使用此版本按钮


    **交互逻辑**：

  • 切换模板时，提示词自动更新
  • 优先使用本次输入的临时提示词
  • 管线运行后显示处理进度
  • 点击"使用此版本"标记选中结果
  • 创建发布任务使用当前选中结果

    • 5.3 模板管理 (TemplatesPage)


    **模板列表**：

  • 名称、分类、语言
  • 启用状态badge
  • 编辑/删除按钮

    • **编辑表单字段**：

    字段类型必填

    5.4 发布中心 (PublishPage)


    **任务列表字段**：

    draft -> pending -> filling -> completed
