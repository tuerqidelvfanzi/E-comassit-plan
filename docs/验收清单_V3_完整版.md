## 测试用例

### TC-01: 插件采集流程
1. 打开Chrome，访问1688商品详情页
2. 点击电商助手插件图标
3. 切换到"采集"标签
4. 点击"采集当前页"
5. 查看采集预览，确认标题/价格/SKU
6. 点击"上传到采集箱"
7. 打开 /app/inbox 确认商品已添加

### TC-02: 标题优化流程
1. 访问 /app/title-optimization
2. 选择目标市场（越南Shopee）
3. 点击"填入示例"或手动输入标题
4. 点击"运行标题优化"
5. 查看多版本优化结果
6. 点击"违禁检测"验证
7. 复制优化标题

### TC-03: SKU生成流程
1. 访问 /app
2. 在SKU生成器中配置:
   - 前缀: BF
   - 颜色: 白色、黑色、蓝色
   - 尺码: S、M、L、XL
   - 启用白色钩子
3. 点击"生成SKU矩阵"
4. 确认生成结果包含正确格式
5. 验证五段编码: BF-0001-PR-WH-S

### TC-04: 主题切换流程
1. 访问 /app/settings/themes
2. 查看36主题分类展示
3. 点击不同分类(浅色/深色/科技/复古)
4. 点击任意主题卡片
5. 观察页面整体样式立即变化
6. 验证顶栏、按钮、卡片等组件样式

### TC-05: 竞品分析流程
1. 访问 /app/competitors
2. 输入关键词"纯棉T恤 女童"
3. 点击"开始分析"
4. 查看分析结果:
   - 高频关键词
   - 价格区间
   - 热门颜色/尺码
5. 查看竞品列表
6. 点击"采集同款"
