## 1. 业务背景

### 1.1 核心痛点

用户当前使用**店八方**工具进行跨境电商上品，存在以下问题：

| 痛点 | 现状 | 期望 |
|------|------|------|
| 手动操作多 | 30-60分钟/商品 | 5分钟/商品 |
| 多平台规则不同 | 越南/泰国/菲律宾规则各异 | 统一配置，自动适配 |
| SKU编码复杂 | 手工填写五段编码 | 自动生成 |
| 图片处理繁琐 | 手动翻译+消除笔 | AI自动处理 |
| 标题本地化 | 人工翻译+字数控制 | AI优化 |

### 1.2 目标

**用AI助手完全替代店八方**，实现：
- 采集 → 处理 → 发布的全流程自动化
- 单商品处理时间从30-60分钟降至5分钟
- 支持多平台（越南Shopee、泰国TikTok、菲律宾Shopee）

### 2.2 采集模块

#### 2.2.1 插件采集

**功能**：浏览器插件从源平台抓取商品数据

**源平台**：
- 淘宝/天猫
- 拼多多
- 1688
- 抖音商城

**采集数据**：
| 数据类型 | 说明 |
|----------|------|
| 商品基本信息 | 标题、价格、销量、评价 |
| SKU变体 | 颜色×尺码组合、价格、库存 |
| 图片 | 主图、详情图、SKU图（9-12张） |
| 属性 | 品牌、材质、尺寸、产地 |

**技术实现**：
- content script 分层抓取（L1 JSON → L2 JSON-LD → L4 DOM）
- 随机延迟防反爬（250-2400ms）
- 用户Cookie模式可选

#### 2.2.2 链接直采

**功能**：粘贴商品URL，后台自动解析

**适用场景**：
- 无法安装插件的环境
- 复杂页面（需Worker处理）

#### 2.2.3 榜单批量采集

**功能**：按类目抓取TOP N商品

**实现**：Playwright + 随机延迟

### 2.3 AI处理模块

#### 2.3.1 标题优化与翻译

**越南Shopee规则**：
- 标题≤20字符
- 汉字压缩到9-10字
- 删除国内标识
- 翻译为越南语

**泰国TikTok规则**：
- 参考同行标题风格
- 翻译为泰语
- 无严格字数限制

**处理流程**：
```
原始标题 → 规则校验 → 语义压缩 → 本地化翻译 → 违禁词检查 → 优化后标题
```

#### 2.3.2 SKU编码生成

**五段式格式**：`{PREFIX}-{SEQUENCE}-{SIDE}-{COLOR}-{SIZE}`

| 字段 | 说明 | 示例 |
|------|------|------|
| PREFIX | 店铺名前缀 | BF |
| SEQUENCE | 序号 0001-1000 | 0001 |
| SIDE | 正反面 P/R/PR | PR |
| COLOR | 颜色编码 | WH/BK/RD |
| SIZE | 尺码 | S/M/L/XL |

**白色钩子**（单款式占位）：
- SKU：`{PREFIX}-9999-P-WH-{SIZE}`
- 价格：400
- 库存：5
- 重量：220g

#### 2.3.3 价格计算

| 市场 | 平台 | 价格公式 | 默认库存 | 默认重量 |
|------|------|----------|----------|----------|
| 越南 | Shopee | 原价 × 3.5 | 50 | 220g |
| 泰国 | TikTok | 原价 × 2.5 | 50 | 220g |
| 菲律宾 | Shopee | 固定500 | 800 | 220g |
| 印尼 | Shopee | 原价 × 3.5 | 50 | 220g |

#### 2.3.4 图片处理

**越南Shopee**：
- 图片数量：9张
- 尺寸：1:1 (800×800px)
- 处理：消除笔 + 中→越翻译

**泰国TikTok**：
- 主图数量：≥5张
- 详情图：4槽固定顺序
- 处理：消除笔 + 中→泰翻译

**需消除的内容**：
- 终身质保、免费退货、包邮
- 商家LOGO、水印
- 厂家介绍、证书资质
- 原价格标签

#### 2.3.5 违禁词检测

**品牌类**（防侵权）：
Nike, Adidas, Disney, LV, Gucci, Chanel, 爱马仕, 苹果, 三星, 华为, NASA

**国内标识**：
3C认证、产地、发货地、品牌名称（除非无品牌）

**面料规则**：
- Cotton ↔ Polyester 不能混用

### 2.4 发布模块

#### 2.4.1 插件填表

**目标平台**：
- 越南Shopee卖家中心
- 泰国TikTok卖家中心

- 可选手动确认
- 失败重试 + 日志

#### 2.4.2 发布状态跟踪

**状态机**：
```
draft → pending → filling → completed/failed
```

**状态说明**：
| 状态 | 说明 |
|------|------|
| draft | 草稿（工作台创建） |
| pending | 待发布（用户确认） |
| filling | 填表中 |
| completed | 已完成 |
| failed | 失败（可重试） |

## 3. 品类SKU模式

### 3.1 品类分类

根据SKU复杂度，将商品分为三类：

| 品类类型 | SKU特点 | 示例 | 模板设计重点 |
|----------|---------|------|--------------|
| A类-多规格服装 | 颜色×尺码矩阵，SKU数量多 | 儿童服装、T恤、裤子 | 五段SKU编码、颜色映射 |
| B类-中规格产品 | 3-5种配置组合 | 吊灯、小家电、收纳盒 | 配置变体、固定SKU |
| C类-少规格/定制 | 少量SKU或需定制 | 橱柜、商用设备 | 支持定制字段 |

### 3.2 A类：多规格服装

**SKU特点**：
- 颜色多（5-10种）
- 尺码多（S/M/L/XL/XXL/XXXL）
- 颜色×尺码矩阵
- 可能需要白色钩子

**模板配置**：
```typescript
{
  id: 'tpl-clothing-multi',
  name: '服装-多规格',
  skuConfig: {
    colors: ['WH', 'BK', 'RD', 'BL', 'GR', 'YL', 'PK', 'PU', 'OR', 'GY'],
    sizes: ['S', 'M', 'L', 'XL', 'XXL', 'XXXL'],
    hasMatrix: true,
    dummyHook: { enabled: true }
  }
}
```

### 3.3 B类：中规格产品

**SKU特点**：
- 3-5种配置选项
- 配置项可能不连续
- 不需要尺码维度

**模板配置**：
```typescript
{
  id: 'tpl-lighting',
  name: '灯具',
  skuConfig: {
    hasMatrix: false,
    variants: [
      { name: '功率', options: ['24W', '36W', '48W'] },
      { name: '色温', options: ['暖光', '白光', '自然光'] }
    ]
  }
}
```

### 3.4 C类：少规格/定制

**SKU特点**：
- 少量固定SKU
- 可能需要用户自定义
- 支持定制参数

**模板配置**：
```typescript
{
  id: 'tpl-cabinet',
  name: '橱柜',
  skuConfig: {
    hasMatrix: false,
    hasCustomization: true,
    customFields: ['宽度', '深度', '高度', '材质', '颜色']
  }
}
```

## 4. 系统提示词设计

### 4.1 系统提示词结构

每个品类模板包含：
1. **基础Prompt**：品类特征描述
2. **规则集**：价格公式、违禁词、字数限制
3. **输出格式**：结构化JSON Schema

### 4.2 服装类模板Prompt示例

```
你是一个跨境电商服装类商品优化专家，专门处理T恤类产品上架越南Shopee和泰国TikTok。

【品类特征】
- 材质：棉质为主
- 图案：正面/背面/正反面
- 变体：颜色×尺码矩阵

【越南Shopee规则】
- 标题≤20字符
- 汉字压缩到9-10字
- 价格=原价×3.5
- 库存=50
- 9张图片，中文翻译为越南语

【泰国TikTok规则】
- 标题参考同行风格
- 价格=原价×2.5
- 主图≥5张
- 五段SKU编码

【输出格式】
{
  "title": "优化后标题",
  "shortDescription": "越南站20字短描述",
  "description": "详细描述",
  "skus": [...],
  "warnings": ["警告信息"]
}
```

## 5. 页面功能

### 5.1 页面列表

| 路由 | 页面 | 功能 |
|------|------|------|
| `/login` | 登录 | 用户认证 |
| `/app` | 工作台首页 | 今日采集/待处理统计 |
| `/app/inbox` | 采集箱 | 商品列表、筛选、批量操作 |
| `/app/workbench/:id` | 处理工作台 | 编辑、运行管线、预览 |
| `/app/templates` | 模板管理 | CRUD类目模板 |
| `/app/rules` | 规则库 | 价格公式、违禁词配置 |
| `/app/insights` | 选品洞察 | GMV/CTR分析 |
| `/app/publish` | 发布中心 | 发布任务队列 |
| `/app/settings` | 设置 | 插件绑定、API Key |

### 5.2 工作台核心功能

**左侧**：原始商品信息（标题、描述、图片、SKU）

**右侧**：
1. 目标平台选择
2. 类目模板选择
3. 临时提示词输入
4. 运行管线按钮
5. 优化结果预览（双指标：高曝光/高转化）
6. 手动编辑区
7. 发布按钮

## 6. 技术架构

### 6.1 分层架构

```
┌─────────────────────────────────────────────┐
│  Web (React 19 + Tailwind v4 + shadcn)      │
│  - 采集箱、工作台、模板、发布                 │
├─────────────────────────────────────────────┤
│  API (Node.js + Express)                    │
│  - REST API、采集任务、商品处理              │
├─────────────────────────────────────────────┤
│  Shared (TypeScript 纯函数)                 │
│  - SKU编码、定价、标题规则、图片规则          │
├─────────────────────────────────────────────┤
│  Extension (Chrome Extension)                │
│  - 采集content script、填表content script   │
├─────────────────────────────────────────────┤
│  Worker (异步任务)                          │
│  - LLM调用、竞品爬取、AI图片处理              │
└─────────────────────────────────────────────┘
```

## 8. 验收标准

### 8.1 功能验收

- [ ] 插件能从淘宝/拼多多采集商品数据
- [ ] 采集箱显示所有采集商品
- [ ] 工作台能运行AI管线生成优化结果
- [ ] SKU编码自动生成（五段式）
- [ ] 价格自动计算（越南×3.5、泰国×2.5）
- [ ] 标题字数校验（越南≤20字）
- [ ] 违禁词检测生效
- [ ] 插件能在目标平台填表
- [ ] 发布状态正确跟踪

### 8.2 性能验收

- [ ] 单商品处理时间≤5分钟
- [ ] 批量处理10商品≤30分钟
- [ ] 页面加载时间≤2秒

### 8.3 质量验收

- [ ] 无品牌侵权内容
- [ ] 无国内标识残留
- [ ] 图片无水印/LOGO
- [ ] 标题符合目标平台规则
