## 本地测试

### 1. 启动前端
```bash
cd web
npm install
npm run dev
```

访问 http://localhost:5173

### 2. 测试功能

#### 采集箱
1. 进入「采集箱」页面
2. 查看Mock商品列表
3. 测试筛选功能（来源/状态）
4. 测试批量选择和删除

#### 标题优化
1. 进入「工作台」页面
2. 输入中文标题：
   ```
   可爱蓝色小熊熊图案卡通印花休闲百搭纯棉短袖T恤儿童韩版
   ```
3. 选择目标平台（越南Shopee）
4. 点击「运行优化」
5. 验证输出越南语标题≤20字符

#### SKU生成器
1. 在工作台页面找到SKU生成器
2. 设置前缀（如BF）
3. 选择颜色（白色、黑色、蓝色）
4. 选择尺码（S、M、L、XL）
5. 点击「生成SKU矩阵」
6. 验证五段编码格式：`BF-0001-PR-WH-S`

#### 违禁词检测
1. 在标题优化中输入含品牌词：
   ```
   Nike运动T恤纯棉儿童百搭
   ```
2. 验证检测到违禁词Nike
