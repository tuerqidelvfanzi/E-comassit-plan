# 用户管理与计费系统 需求规格书

版本: V1.0
日期: 2026-06-01
状态: 待开发

---

## 1. 用户管理系统

### 1.1 功能架构

- 认证模块: 邮箱注册/登录, 社交登录, 邮箱验证, 密码重置
- 授权模块: RBAC角色, 资源权限, API Key管理
- 团队模块: 团队创建, 成员邀请, 角色分配, 使用配额

### 1.2 角色定义

| 角色 | 说明 | 权限 |
|------|------|------|
| Owner | 团队所有者 | 全部权限 |
| Admin | 管理员 | 管理成员/设置/充值 |
| Member | 成员 | 使用功能/查看消耗 |
| Viewer | 观察者 | 只读访问 |

## 2. 费用消耗系统

### 2.1 API消耗计算

| 操作 | 预估输入Tokens | 预估输出Tokens |
|------|---------------|----------------|
| 标题优化 | 200 | 50 |
| 描述改写 | 500 | 300 |
| SKU生成 | 100 | 150 |
| 竞品分析 | 1000 | 800 |
| 图片OCR | 500 | 200 |

### 2.2 预警规则

| 级别 | 阈值 | 动作 |
|------|------|------|
| 提醒 | 余额<50% | 推送通知 |
| 警告 | 余额<20% | 推送+邮件 |
| 紧急 | 余额<10% | 推送+短信 |
| 熔断 | 余额=0 | 暂停服务 |
