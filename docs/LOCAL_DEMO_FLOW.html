第一部分 · 使用说明

面向零基础操作者：每个菜单干什么、按什么顺序点、成功时长什么样。

1. 菜单说明与相互关系

登录后左侧共 8 个菜单。处理工作台不是菜单，从采集箱点「编辑」进入。

每个菜单做什么？

菜单路径功能什么时候来
工作台/app首页统计、五步引导、下载插件刚登录；看还有多少待处理
采集箱/app/inbox商品列表；来源/关键词/日期筛选；可上传图片插件上传后；要处理/删除
批量采集/app/batch-collect填榜单 URL 一次抓多条不想一页页用插件时
类目模板/app/templatesPrompt + SKU 前缀/颜色/尺码/Hook（悬停看编码建议）跑管线前改模板
规则库/app/rules定价、标题字数、违禁词改越南价公式等
选品洞察/app/insights热词、竞品特征参考可选，不写回商品
发布中心/app/publish发布任务、生成填表商品「可发布」之后
设置/app/settings下载插件、复制令牌、主题、LLM第一次必来

菜单主链路（Mermaid）

大步骤 ↔ 菜单对照

步骤主要菜单还要配合
0 准备（无）终端 api + web/login
1 装插件设置Chrome 插件 Popup
2 采集插件 → 采集箱或 批量采集
3 处理采集箱 → 处理工作台模板/规则/洞察（可选）
4 填草稿发布中心插件 + 卖家网站
5 上架（无 B 站菜单）Shopee / TikTok / 淘宝卖家后台

2. 小白逐步操作手册

按顺序做即可。口诀：设置装插件 → 采集箱收货 → 编辑做处理 → 发布中心出货 → 卖家后台点发布

步 做什么 怎么点 成功标志
0 跑起来 ① cd api → npm run dev
② cd web → npm run dev
③ 打开 localhost:3004/login		 左侧出现 8 个菜单
1 登录 admin01 / abcd234 → 登录 进入工作台首页
2 连插件 设置 → 下载插件 → Chrome 加载 extension/
复制令牌 → Popup 填后台/API/令牌		 Popup 三项填齐
3 采 1 个品 1688/淘宝详情页 → 插件「采集当前页」→「上传」→ 采集箱 提示 API 写入；列表多一行「插件」
3′ 采很多条 插件同步 Cookie → 批量采集 → 开始 → 采集箱 任务 done；多条新货
4 处理 采集箱 → 编辑 →「运行管线」 高曝光/高转化；状态「可发布」
5 准备发布 发布中心 → 新建 →「生成填表」 校验「通过」
6 填草稿 卖家后台新建页 → 插件「填入」→ 发布中心「标记已填入」 Toast 已填入；completed
7 上架 卖家后台核对 → 点平台「发布」 平台显示已上架

我想做 X，去哪个菜单？

我想…菜单按钮
配置插件设置下载插件、复制令牌
看采了哪些货采集箱—
改标题/SKU/短描述采集箱 → 编辑编辑内容 → 保存；运行管线
图片去水印/翻译处理工作台消除笔、中→越翻译
一次采 10 条批量采集开始批量采集
发到 Shopee/TikTok发布中心生成填表 → 插件填入

3. 演示版 v2 新功能速览

本轮重点：Web UI 接线（采集箱筛选、工作台编辑、模板 SKU 配置）。插件填表与真实 LLM/图片 Worker 仍属下一轮。
页面新能力操作提示
采集箱 来源筛选、关键词、日期范围（API GET /products?source=&keyword=&dateFrom=） 工具栏选条件 → 列表即时刷新；可「清空筛选」
处理工作台 标题字数/汉字统计；短描述≤20；SKU 表编辑；双栏对比；消除笔/翻译按钮 点「编辑内容」→ 改完「保存」→ 再「运行管线」
类目模板 PREFIX、颜色、尺码、印花后缀、Hook；悬停「编码建议 ⓘ」按类目+市场提示 展开 SKU 配置 → 保存后写入 sku_config_json

SKU 编码灵活性（产品方向）

不同国家/品类/店铺规则不同：演示阶段用模板级 skuConfig + 悬停 Tips；正式版建议「规则引擎 + 可配置脚本」，五段/六段由店铺策略决定，勿写死在单一 encode 函数。
